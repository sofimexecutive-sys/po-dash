# Product Lead · Кибершеф — recruitment dashboard

Отдельный дашборд на базе CFO dashboard v4.

## Вакансия
- Текущее название в Talantix: `Product Lead || Кибершеф`
- Старое название: `Product Lead (Кибершеф)`
- Оба названия объединяются в одну вакансию `Product Lead`, поэтому кандидаты до и после переименования показываются вместе.

## Логика
- `Неразобранные` отображаются как этап **Пристрелка**.
- Оценщик: **Никита**.
- На «Пристрелке» две независимые оценки 1–10: попадание в профиль и попадание в компанию.
- Оценку можно снять через вариант «Без оценки».
- Комментарии Никиты сохраняются отдельно в базе дашборда.
- **Комментарии рекрутера из Talantix (`Комментарий 1/2/3`) отображаются в карточке кандидата.**
- Резюме и ссылка на Talantix сохраняются в карточке кандидата.
- Данные кандидатов читаются из свежего Drive-отчёта; snapshot используется как fallback.

## Railway variables
Такие же, как у CFO-дашборда: `REPORT_SOURCE_URL`, `DATABASE_URL`; для аналитики также `FUNNEL_SOURCE_URL`, `PROCESS_SOURCE_URL`.
